## Findings

Every finding has a source; `fix now` ones were applied in this retro (see Behavior verification), `defer` ones are action items.

### Architecture delta

- **F1. The shared renderer carries the name of one scene type.** `lib/numbermodel` (`Prim`, `Sentence`) and `scenes/numbermodel/NumberModel.tsx` are consumed by `lib/algebra`, `lib/trig`, `lib/stats` and by four viewers (`src/features/scene/{NumberModel,AlgebraTool,Trig,Stats}Viewer*.tsx`). It works and the layer lint (`eslint-plugin-boundaries`, part of `npm run check`) is green, but a reader looking for the stats renderer will not look in `numbermodel`. Disposition: defer (rename to a neutral module); lesson: name a module for what it is when the second consumer arrives.
- **F2. A new contract: `SceneDefinition.check`.** Story 3.4 added a per-scene stage-S5 hook run by `createTopicValidator` after the schema (`src/lib/topic-schema/scene-registry.ts`, `validate.ts`). It is the first recompute check of the upload pipeline and is not in the architecture documents. Disposition: accept, record in the documentation story.
- No import cycles were added by the epic (`lib/params` still has the one of Epic 2's item 14: `steps.ts:1` and `url.ts:2` import `./index`).

### Duplication map

- **F3. One number formatter, six copies.** `trim`/`fmt` is defined in `src/features/scene/Canvas2DViewer.tsx:48`, `src/features/scene/SolidViewer.tsx:85`, `src/lib/algebra/build.ts:45`, `src/lib/numbermodel/build.ts:81`, `src/lib/stats/charts.ts:51` and `src/lib/trig/values.ts:81`. Four are the same one-liner. Disposition: defer; lesson: when a helper is written the second time, move it to `lib/format`.
- **F4. Three handle components, one pointer routine.** `src/features/scene/Handles.tsx`, `ModelHandles.tsx` and `AngleHandle.tsx` each hold the same pointer-capture, focus, wheel-stop and keyboard code. The Story 3.3 review fix (primary button only, stop when no button is held, focus after `preventDefault`) had to be applied to two files, and the Story 3.5 handle was born with it (commits `ae32b29`, `2e9f191`). A fourth handle would have to be fixed a fourth time. Disposition: defer (one `usePointerHandle` hook).
- **F5. Six viewers share a body.** `const parts: ViewerParts` and the "what the picture shows" list are repeated in `Canvas2DViewer`, `NumberModelViewer`, `AlgebraToolViewer`, `TrigViewers` (`finish`), `StatsViewer` and `SolidViewer`. Disposition: defer (a `ViewerShell`).
- **Win:** the stroke and fill token tables were duplicated in `Canvas2D` and the legend; Story 3.3 moved them to `src/scenes/tokens.ts`, now used by both renderers.

### Pattern divergence

All six scene types follow one shape: meta and schema in `lib/topic-schema/scenes`, pure layout in `lib/<name>`, pure renderer in `src/scenes`, viewer on `useSceneState` in `src/features/scene`, fixture, unit and e2e tests. This is the epic's main result: a new scene type touched the topic page only in `viewers.tsx` (one line) and `TopicPage` once (3.1). Divergence is intentional: `Canvas2D` draws from `Drawables` with a viewport, zoom and pan, while the other five draw flat prims. Accept.

## Process lessons

From the session transcript (the only record of what was tried and dropped):

- **Shell heredocs and CRLF wasted many calls.** Python or `sed` edits through bash lost backslashes and apostrophes, and checked-out files have CRLF, so exact-match replacements failed (Stories 3.2, 3.4, 3.5: edit scripts failed three to four times before a file-based script or the Edit tool worked). Lesson: the Write and Edit tools; settle line endings in the repository (action 8).
- **A stale build can pass.** When `npm run check` aborts at a failing unit test, Playwright runs the previous build. It happened again in 3.5 and 3.6 and was noticed only by reading the first failure line. Lesson: Epic 2 item 15 (`check:e2e`) has recurring cost.
- **A flaky suite was fixed, not rerun.** The PGlite migration tests timed out in `beforeAll` at the 10 s default on a busy machine (twice, Stories 3.5 and 3.6); `hookTimeout: 60000` is now in `vitest.config.ts` (commit `fa18046`).
- **One branch per epic and a commit per story worked:** six commits, each green on `npm run check`, a clean per-story diff for every review.
- **The three reviewers pay for themselves** (F10, Diff-scope review); the usage-limit failures of Epic 2 did not recur.
